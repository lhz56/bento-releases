# Bento for Mac

Signed, notarized builds of Bento, the Mac app that teaches how software is really built, with the AI you already pay for.

**[Download for Mac (Apple Silicon)](https://github.com/lhz56/bento-releases/releases/latest/download/Bento-arm64.dmg)** · [Intel](https://github.com/lhz56/bento-releases/releases/latest/download/Bento-x64.dmg) · macOS 12 or newer

Open the `.dmg`, drag Bento into Applications, and open it from there. Bento updates itself from this page.

Found a problem? [Open an issue](https://github.com/lhz56/bento-releases/issues/new) (Bento → Report a Problem… fills in the version for you).
