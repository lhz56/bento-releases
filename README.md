# Bento for Mac

Study how software works with lessons you can run, edit, and step through. Explore a real project, or connect a supported AI tool on your Mac to ask your own questions.

**[Download for Apple Silicon](https://github.com/lhz56/bento-releases/releases/latest/download/Bento-arm64.dmg)** · **[Download for Intel](https://github.com/lhz56/bento-releases/releases/latest/download/Bento-x64.dmg)**

Requires macOS 13 Ventura or newer. In **Apple menu → About This Mac**, choose Apple Silicon if you see an Apple M-series chip, or Intel if you see an Intel processor.

1. Open the downloaded disk image and drag **Bento** to **Applications**.
2. Open Bento from Applications. Choose **Try a lesson** to draw a spiral and change its code.
3. Choose **Connect my AI** in the welcome, or open **Settings → Connections** later. Use the provider’s subscription sign-in to study with an eligible plan. API keys and cloud accounts have separate billing.

The Mac builds are signed and notarized. Bento checks for updates automatically. Use **Bento → Report a Problem** to send feedback with the app version, or [open an issue](https://github.com/lhz56/bento-releases/issues/new).
